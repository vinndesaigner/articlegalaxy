Bab 2: Kategori Utama CTF

Kompetisi CTF (Capture The Flag) umumnya dibagi menjadi beberapa kategori kompetensi dasar:

🌐

Web Exploitation

Analisis source code web, cookie, header HTTP, hingga celah injection.

🕵️‍♂️

Forensics & OSINT

Mencari metadata/pesan tersembunyi di file gambar, audio, atau jaringan.

🔐

Cryptography

Memecahkan enkripsi dan encoding data (Base64, Rot13, Hash, dll).

Bab 3: CTF Lab & Walkthrough

Dokumentasi langkah demi langkah penyelesaian tantangan CTF berbasis screenshot.

Web Exploitation

Challenge #1: Hidden Source Code

Tingkat Kesulitan Easy (100 Pts)

📋 Deskripsi Soal

Pengembang aplikasi lupa menghapus komentar rahasia pada halaman web. Temukan flag yang tersembunyi di dalam struktur dokumen!

🛠️ Tools Yang Digunakan

Browser (Chrome/Firefox) Developer Tools (Inspect Element)

🚀 Langkah-Langkah Penyelesaian (How To Find)

1
Buka Developer Tools Browser

Akses web target, klik kanan pada halaman utama lalu pilih Inspect (atau tekan tombol F12).

Gambar 1.1: Membuka Tab Elements di Developer Tools
2
Temukan Kode Flag pada HTML Comment

Telusuri bagian baris kode HTML. Cari tag komentar <!-- ... --> untuk menyalin string flag.

Gambar 1.2: Kueri flag berhasil ditemukan
